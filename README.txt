# Massachusetts Distance Project — First Website Version

This is a simple, responsive static website for Massachusetts Distance Project.

## Files

- `index.html` — the complete homepage
- `styles.css` — design and responsive layout
- `script.js` — mobile navigation and article filters
- `assets/mdp-logo.png` — the MDP logo

## How to use it

Open `index.html` in a browser to preview the site.

The placeholder race photos and videos are intentionally simple. Replace them with your own content as the project grows.

### Adding a real article

The easiest first approach is to duplicate an article card in `index.html` and change:
- the category/date
- headline
- description
- article link
- photo

Later, the site can be upgraded to a proper article-management system so you don't have to edit HTML manually.

### Adding photos

You can replace the placeholder photo blocks with your gallery links. The site does not need to host the original images itself.

### Adding interviews

You can replace the video placeholders with YouTube embeds or links to your interview videos.

## Free hosting

Because this is a static website, it can be hosted on several free services. A future version can be prepared specifically for whichever free host you choose.
