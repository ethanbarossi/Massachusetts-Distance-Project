About MDP

Massachusetts Distance Project

Massachusetts Distance Project is an independent media project covering high school cross country and distance running throughout Massachusetts.

MDP focuses on the athletes, teams, races and stories that make Massachusetts distance running special through articles, rankings, photography, interviews and race coverage.
